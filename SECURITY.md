# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Apex Music Player, please report it privately:

1. **Do not create a public issue**.
2. Open a security advisory on GitHub under the **Security** tab, or email the maintainers directly.
3. Include detailed steps to reproduce the vulnerability, along with relevant device / OS versions.
4. We aim to acknowledge reports within 48 hours and provide a fix or mitigation promptly.

Thank you for helping keep Apex Music Player and its users secure!
